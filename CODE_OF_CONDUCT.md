# Code of Conduct

This is a project about giving software a computer and getting real work out
of it. The rules for people are short.

## The rules

1. **Talk about the work.** Issues, pull requests and discussions are for the
   code, the docs and how agents behave. Bring a repro, a diff or a question.
2. **Be direct and be decent.** Say what is wrong and why. Criticise code,
   ideas and decisions as hard as you like; do not attack people.
3. **No harassment.** No threats, no stalking, no doxxing, no posting anyone's
   private details, no unwanted sexual content. This is not complicated.
4. **No spam, no scams.** No drive-by advertising, no crypto shilling, no
   fake bug reports, no AI-generated filler issues.
5. **Own your mistakes.** Everyone breaks something eventually. Say so, fix
   it, move on. Nobody gets dragged for an honest error.
6. **Security problems go to the maintainer first.** See
   [SECURITY.md](SECURITY.md). Do not open a public issue for an exploit.

## Enforcement

The maintainer ([@BryantVanOrden](https://github.com/BryantVanOrden)) decides
what crosses the line. Comments get edited or deleted, repeat offenders get
blocked. No committee, no appeals process. Report a problem by opening an
issue, or through the contact details on the maintainer's GitHub profile if
it is sensitive.

## Scope

Anywhere this project is discussed under its name: this repository, its wiki
and discussions, and anywhere someone is officially representing it.

Ship good work and treat people like adults. That is the whole thing.
